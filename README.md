# Supermercado
## Como rodar o Back-end?
- 1º passo\
No terminal, rodar: Npm init -y
- 2º passo\
No terminal, rodar: Npm install
- 3º passo\
No terminal, rodar: Npm install express
- 4º passo\
No terminal, rodar: Npm install nodemon
- 5º passo\
No terminal, rodar: Npm install cors dotenv @supabase/supabase-js
- 6º passo\
No terminal, rodar: Node server.js
